# vis-inference-evals.github.io

Static site. `claim2_2/` is the claim 2.2 entity-chain Streamlit dashboard, run in the browser with
[stlite](https://github.com/whitphx/stlite). It is generated, not hand-edited: rebuild it from the
analysis repo with

    uv run python -m analysis.claim2_2.site.build <path-to-this-repo>
